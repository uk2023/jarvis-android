# JARVIS Android Control Layer

Native Android control layer for JARVIS.

## Goal

Provide JARVIS with human-like Android interaction capabilities:

- Tap
- Long press
- Swipe
- Scroll
- Back
- Home
- Recent apps
- Text input
- Drag
- Gesture sequences
- Coordinate-based interaction
- Accessibility-based semantic interaction
- Human-like timing and gesture behavior

JARVIS cognition, memory, identity and existing runtime remain external to this project.

This repository focuses only on the Android control/action layer.
